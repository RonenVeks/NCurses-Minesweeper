## About
Well, to be honest, I had already made a CLI Minesweeper game in the C programming language before. But I decided to recreate it for two reasons:
- The first time I did it - it was for the Windows CMD, which required me to clear the entire screen every time I wanted to make a change in the display. This boundery makes the game experience slightly unsatisfying.
- The code itself was absolutely horrible.

<br/>

## Running the game
<p>Run the following command in order to clone the repository:</p>

``` bash
git clone https://github.com/RonenVeks/NCurses-Minesweeper.git
```
<br/>
<p>Then, execute the compilation shell script:</p>

``` bash
./build.sh
```
<br/>
<p>And finally, run the following command in order to start the actual game:</p>

``` bash
./minesweeper
```
